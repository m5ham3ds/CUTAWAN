# Phase 1 — Native Android foundation, Flutter shell and ARM64 packaging

**Current state:** implementation delivered; automated application and packaging gates have passed on prior source snapshots. Physical installation/startup and OEM acceptance remain open.

## Objective

Create CUTAWAN as a genuine Android phone application without replacing or embedding the existing Electron desktop application.

## Implemented scope

- Flutter/Dart is the mobile product target at `mobile/flutter_app/`.
- Material 3 shell and phone-first navigation are implemented.
- Current routes include Dashboard, Create, Jobs, Review, Clip Editor, Caption Studio, Settings, Models Center and Device Diagnostics.
- Arabic RTL and English LTR are supported by the Flutter presentation layer.
- Android platform integration is generated by `tooling/generate_android_platform.sh`; native Android code is maintained in `tooling/android/`.
- CI pins Flutter 3.47.6, generates the Android project and builds a debug APK for `android-arm64`.
- ARM64 packaging checks require `arm64-v8a`, verify the expected native libraries, and reject duplicate native-library basenames.

## Source map

- `lib/screens/home_shell.dart` — application shell and route composition.
- `lib/screens/home_shell/navigation_components.dart` and `shared_ui_primitives.dart` — shared navigation/UI primitives.
- `lib/screens/features/` — Dashboard and Settings screens plus feature-level editor screens.
- `tooling/android/MainActivity.kt` — Android method-channel bridge and native entry point.
- `.github/workflows/mobile-android.yml` — current Android CI workflow.
